# Deploying to Cloudflare

The commands below were not run in this environment because no Cloudflare account was available.
They must be run in order, from a machine with `wrangler` authenticated against the target Cloudflare account.

## 1. Create the Vectorize index

```bash
npx wrangler vectorize create zane-kb --dimensions=1024 --metric=cosine
```

This must match the `VECTORIZE` binding's `index_name` (`zane-kb`) and dimensions (`1024`, the `bge-m3` output size) declared in `wrangler.jsonc`.

## 2. Set production secrets

```bash
npx wrangler secret put DEEPSEEK_API_KEY
```

Also set `DEEPSEEK_BASE_URL` (the AI Gateway DeepSeek endpoint) as a plain (non-secret) var in the deploy environment, since it is not sensitive.

## 3. Regenerate the KB index with real embeddings

`src/lib/rag/kb-index.json` currently holds a placeholder generated by `scripts/gen-placeholder-index.ts`, with deterministic fake vectors.
It must never be seeded to production Vectorize, because retrieval over fake vectors is meaningless.
Regenerate it with real Workers AI embeddings before seeding:

```bash
set -a && . ./.env.local && set +a
pnpm kb:build
```

This requires `CF_ACCOUNT_ID` and `CF_API_TOKEN` to be set (see `.env.local.example`).
It overwrites `src/lib/rag/kb-index.json` with real `bge-m3` vectors and clears the `placeholder` flag.

## 4. Seed Vectorize

```bash
set -a && . ./.env.local && set +a
tsx scripts/seed-vectorize.ts
```

This reads the (now real) `kb-index.json` and upserts every chunk into the `zane-kb` Vectorize index via the Cloudflare HTTP API.
It refuses to run if `kb-index.json` still has the `placeholder` flag set, or if `CF_ACCOUNT_ID`/`CF_API_TOKEN` are missing.
Expected output: a line reporting the number of vectors upserted.
Verify with:

```bash
npx wrangler vectorize get zane-kb
```

This should show a non-zero vector count.

## 5. Build and deploy

```bash
pnpm cf:build
npx opennextjs-cloudflare deploy
```

Expected result: a live URL.
Confirm chat answers stream, citations show, off-topic questions refuse, and contact questions return exact facts.
